一、系统简介
──────────────────────────────────────────────────────────────

本系统是一套轻量级的仓库进出管理工具，适用于小型仓库、部门
物资管理等场景。

特点：
  · 双击即可运行，无需安装数据库或任何软件
  · 支持多人局域网同时登录操作
  · 三级权限控制，适配不同岗位
  · 出入库记录可追溯，支持 Excel 导出
  · 软删除 + 回收站机制，误删可恢复


二、快速开始
──────────────────────────────────────────────────────────────

1. 双击「仓储管理系统.exe」，等待 5-10 秒解压启动

2. 看到以下信息表示启动成功：
   [OK] 数据库已连接
   [START] 仓库管理系统启动中...
   本地访问:    http://127.0.0.1:5000
   局域网访问:  http://192.168.x.x:5000

3. 浏览器会自动打开登录页面，如未打开请手动访问上述地址

4. 使用默认账号登录（详见下一节）

5. 关闭：直接关闭黑色终端窗口，或按 Ctrl+C


三、账号与权限
──────────────────────────────────────────────────────────────

系统内置三个默认账号，首次启动自动创建：

  ┌───────────┬──────────────┬────────┬────────────────────┐
  │  用户名   │    密码      │  角色  │      可操作范围    │
  ├───────────┼──────────────┼────────┼────────────────────┤
  │ admin_H   │  admin001    │ 管理员 │ 所有功能           │
  │ admin_M   │  admin002    │ 操作员 │ 入库/出库/查看     │
  │ admin_L   │  admin003    │ 访  客 │ 仅查看，不可操作   │
  └───────────┴──────────────┴────────┴────────────────────┘

权限明细：

  管理员：仪表盘 + 实时库存 + 商品管理(新增/删除) +
          入库操作 + 出库操作 + 每日明细 + 导出Excel +
          回收站(恢复/永久删除)

  操作员：仪表盘 + 实时库存 + 商品管理(仅查看) +
          入库操作 + 出库操作 + 每日明细 + 导出Excel

  访  客：仪表盘 + 实时库存 + 每日明细(仅查看)


四、功能详解
──────────────────────────────────────────────────────────────

4.1 仪表盘（首页）
    ──────────────
    登录后的首页，展示仓库关键指标：
    · 商品种类数
    · 库存总量
    · 今日入库 / 今日出库
    · 低库存预警条数
    · 低库存商品明细（Top 10）
    · 最近 5 条入库 / 出库记录

4.2 实时库存
    ──────────
    查看所有商品当前库存状态，支持：
    · 按名称/编码/库位搜索
    · 按分类筛选
    · 只看低库存（库存 ≤ 安全下限）
    · 库存为零或低于安全下限的会红色/橙色高亮

4.3 商品管理（仅管理员/操作员可见入口）
    ──────────────────────────────────
    查看所有商品列表，管理员可：
    · 点击「新增商品」按钮添加新商品
    · 点击垃圾桶图标将商品移入回收站
    · 删除商品不影响已有的出入库历史记录
    必填项：商品名称、商品编码（不可重复）

4.4 入库操作（管理员/操作员）
    ──────────────────────────
    选择商品 → 填写数量 → 提交（库存自动增加）
    · 供应商、操作人、备注为选填
    · 可在顶部「快速新增商品」直接添加新商品并入库
      （仅管理员）

4.5 出库操作（管理员/操作员）
    ──────────────────────────
    选择商品 → 填写数量 → 提交（库存自动扣减）
    · 领用人/客户、操作人、备注为选填
    · 库存不足时自动阻止出库并提示

4.6 每日明细
    ──────────
    按日期查询入库和出库记录：
    · 默认显示当天
    · 可切换任意历史日期查看
    · 显示合计数量
    · 管理员可删除单条记录（移入回收站）

4.7 导出数据（管理员/操作员）
    ──────────────────────────
    点击侧边栏「导出全部数据」，生成 Excel 文件（.xlsx）。
    包含三个工作表：
    Sheet 1 — 实时库存（当前所有商品库存快照）
    Sheet 2 — 全部入库明细（所有历史入库记录）
    Sheet 3 — 全部出库明细（所有历史出库记录）

4.8 回收站（仅管理员）
    ───────────────────
    存放已删除的商品和出入库记录，可：
    · 点击「恢复」按钮还原数据
    · 点击「永久删除」彻底移除（不可恢复）
    · 超过 30 天的记录系统自动永久清理


五、局域网共享
──────────────────────────────────────────────────────────────

系统启动后，同一 WiFi/局域网内的其他电脑可通过浏览器访问：

1. 在运行程序的电脑上，查看终端输出的「局域网访问」地址
   格式：http://192.168.x.x:5000

2. 其他电脑在浏览器输入该地址即可打开登录页面

3. 多人可同时登录操作，数据实时同步

注意：
  · 所有电脑必须在同一局域网（连接同一个路由器/WiFi）
  · 运行程序的电脑关闭后，其他人将无法访问
  · 如果无法访问，检查主机防火墙是否拦截了 5000 端口


六、数据备份
──────────────────────────────────────────────────────────────

所有数据存储在程序同级目录的「data」文件夹中：

  仓储管理系统/
  ├── 仓储管理系统.exe     ← 主程序
  └── data/
      └── warehouse.db     ← 数据库文件（所有数据）

备份方法：
  复制「data」文件夹保存到其他位置即可。

恢复方法：
  将之前备份的「data」文件夹放回程序同级目录，重启程序。

注意：
  · 建议定期备份 data 文件夹
  · 升级程序版本时，保留 data 文件夹即可延续原有数据
  · 删除 data 文件夹将丢失所有数据，程序重启后会自动创建
    空数据库（含三个默认账号）


七、常见问题
──────────────────────────────────────────────────────────────

Q1：双击 EXE 没反应，或提示缺少 DLL？
A：  Windows 7 需安装 VC++ 运行库（vc_redist.x64.exe），
    Windows 10/11 通常已内置。如缺少可从微软官网下载。

Q2：浏览器打开后显示"无法访问此网站"？
A：  等待终端窗口出现启动完成信息后再刷新浏览器。
    首次启动有 5-10 秒解压延迟。

Q3：局域网其他电脑访问不了？
A：  ① 确保在同一个局域网
    ② 在主机上打开「Windows 防火墙」→ 允许应用通过防火墙
       → 允许 Python（或 仓储管理系统.exe）通过
    ③ 尝试在主机浏览器访问 http://127.0.0.1:5000 确认服务正常

Q4：端口被占用怎么办？
A：  默认端口 5000。如果冲突，修改 config.py 中的 PORT 为重
    新打包，或联系管理员提供其他端口的版本。

Q5：忘记密码？
A：  删除 data/warehouse.db 文件，重启程序即可恢复三个默认账号。
    但这会清除所有数据，请先备份。

Q6：能不能自己修改默认账号和密码？
A：  可以，修改 app.py 中 init_db() 函数里的 default_users 列表，
    重新打包即可。已创建的账号不会被覆盖。

Q7：商品删除后入库记录里的商品名称变成了"(已删除商品)"？
A：  这是正常设计。删除商品不会删除历史记录，商品名显示为
    占位文本以保留溯源信息。
